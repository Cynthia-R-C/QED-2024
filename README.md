# QED-2024 Apollonian Gasket Generator
This is the Python code for my 2024 QED project.

## Directions to Run
The "step" files are meaningful saved versions (I coded this earlier on before I learned about Github version control, so this was my way of keeping track). To run the program, run the QED_2024-2025_runnable_final.py.

Amount of points to take on each figure: pick any number from 2000 to 4000
Straight or circular configuration: only enter “straight” if you entered the same radii for all three. You can enter “circular” for any radii you try.

Because this requires the Apollonian gaskets to be integral, not all sets of initial radii are valid. Feel free to search online for additional sets of initial radii Apollonian gaskets, but here are examples you can try out:

Radii:
1, 1, 1
½, ½, ⅓
⅛, ⅛, ⅕
125, 125, 128
110, 115, 119
118, 123, 127

DO NOT choose a layer number larger than 5 if you want quick results. 

Graph Ford circles: Your choice on this one!

(You may need to use the mouse to scale and resize the application window for the best view.)
